# Jade Lion Studios

This repository provides one permanent public doorway to two tabletop roleplaying projects:

- **Protocol 7** — a complete time-intelligence and covert-action roleplaying game
- **Protocol Dice Engine** — the setting-agnostic, classless rules engine

Public hub: <https://jnarquitt.github.io/>

The site is deliberately simple. `index.html` contains the complete visual page and works locally without an installation or web server. `og.png` provides the social-sharing preview.
